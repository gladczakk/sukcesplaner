# ProjectDot

A 10px dot in the project's color, shown before the project name everywhere a task or milestone appears (FR-014).

Classes `sp-dot sp-dot--sage|kensington|ochre|brick|teal|sand`; `sp-dot--lg` (14px) in nav and project headers. Assign colors to projects in creation order and let the user change it. The dot always sits next to the project's name; it never stands alone.

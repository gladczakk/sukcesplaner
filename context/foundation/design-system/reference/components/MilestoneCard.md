# MilestoneCard

A milestone in the right rail: name, project, countdown chip, date and progress bar.

**Provide:** milestone name, project name + color, date, tasks done/total, overdue count. `sp-ms--risk` (ochre border) when the milestone is within 2 days and has open tasks; `sp-ms--late` (brick border) when its date has passed (FR-015). The rail lists the next 3–5 milestones across all projects, nearest first. The mark is a diamond in the project color; the diamond means *milestone* everywhere in the product.

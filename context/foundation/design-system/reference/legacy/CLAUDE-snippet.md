## Design system

All UI follows the SukcesPlaner design system in `.claude/skills/sukcesplaner-design-system/`.
Before any UI work (screens, components, styles, copy) read `.claude/skills/sukcesplaner-design-system/SKILL.md`.
- Import `tokens/tokens.css` once in the root layout; use the Tailwind preset `tokens/tailwind.preset.js`.
- Never hard-code colors, fonts, spacing or radii; use tokens only.
- Reference screens (desktop + mobile, light + dark screenshots): `reference/screens/` — day-view, calendar-view, project-view.
- UI language: Polish.

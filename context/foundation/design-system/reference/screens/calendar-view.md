# CalendarView

Kalendarz at desktop width: month grid in the main column, the selected day's deadlines in the right rail.

Header: eyebrow *Kalendarz*, month + year in `display`, prev / *Dziś* / next buttons. Then life-area filter and a legend. Rail: selected date in `section`, a note that this shows deadlines (the plan is in *Dziś*), MilestoneCards for that day, task rows with that deadline, *Dodaj milestone*.

# DayView

The day view (lista na dziś) at desktop width: sidebar, list, milestone rail.

Order on screen: eyebrow *Dziś* → date in `display` → summary counts (items, overdue in `brick-ink`, milestones to close) → primary *Dodaj zadanie* → life-area filter → the sorted task list → rail with *Najbliższe milestony*. Main column padding `space-7` top, `space-6` sides; rail 300px.
